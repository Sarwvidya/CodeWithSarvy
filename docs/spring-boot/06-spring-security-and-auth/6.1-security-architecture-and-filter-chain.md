# 6.1 Security Architecture & Filter Chain

[← Back to Chapter 6: Spring Security & Authentication](./index.md)

Spring Security provides authentication, authorization, and protection against exploits (such as CSRF and session fixation). Its foundational architecture operates as a chain of servlet filters.

---

## 1. Filter Chain Architecture

Servlet containers maintain a native filter chain. Spring bridges this standard servlet environment to the Spring IoC container using `DelegatingFilterProxy`:

```
[ Inbound HTTP Request ]
          │
          ▼
[ Standard Servlet Filters ]
          │
          ▼
┌──────────────────────────────────────────────────────────┐
│ DelegatingFilterProxy (Standard Servlet Filter)          │
│ └── Delegates execution to Spring-managed bean:          │
│     FilterChainProxy (springSecurityFilterChain)         │
└───────────────────────────┬──────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────┐
│ SecurityFilterChain (List of Security Filters)           │
│  1. HeaderWriterFilter (Adds security headers)           │
│  2. CorsFilter (Handles CORS preflight OPTIONS)          │
│  3. CsrfFilter (CSRF token verification)                 │
│  4. JwtAuthenticationFilter (Custom token parser)        │
│  5. UsernamePasswordAuthenticationFilter                 │
│  6. SecurityContextHolderFilter                          │
│  7. AuthorizationFilter (Enforces URL path permissions)   │
└───────────────────────────┬──────────────────────────────┘
                            │
                            ▼
               [ DispatcherServlet ]
```

---

## 2. Authentication vs Authorization

- **Authentication (AuthN)**: "Who are you?" Validates identity using credentials (passwords, JWTs, API keys, OAuth2 tokens). Produces an `Authentication` principal.
- **Authorization (AuthZ)**: "What are you allowed to do?" Determines whether the authenticated principal has permission to access the requested resource or method (`ROLE_ADMIN`, `order:write`).

---

## 3. The Core Security Abstractions

```
AuthenticationManager (authenticate())
          │ delegates to
ProviderManager
          │ tries list of
AuthenticationProvider (e.g. DaoAuthenticationProvider)
          │ loads user via
UserDetailsService (loadUserByUsername())
          │ compares password with
PasswordEncoder (matches(raw, encoded))
```

1. **`SecurityContextHolder`**: Holds the `SecurityContext` for the current execution thread (by default via `ThreadLocal`).
2. **`SecurityContext`**: Stores the current `Authentication` object.
3. **`Authentication`**: Contains the principal (user identity), credentials, and granted authorities (`Collection<? extends GrantedAuthority>`).
4. **`AuthenticationManager`**: The API defining how Spring Security filters execute authentication.
