# 7.3 Object Reachability & Java Reference Types

[← Back to Chapter 7: Garbage Collection & Serialization](./index.md)

Java provides fine-grained control over object lifecycle through the `java.lang.ref` package, categorized into 4 levels of reference strength.

---

## 1. The 4 Levels of Reference Strength

```
Strong Reference ──► Soft Reference ──► Weak Reference ──► Phantom Reference
(Never collected)   (Collected only     (Collected on     (Used for post-mortem
                     on low memory)      next Minor GC)    resource cleanup)
```

| Reference Type | Class | GC Collection Trigger | Primary Use Case |
| :--- | :--- | :--- | :--- |
| **Strong** | Standard (`User u = new User()`) | Never collected while reference exists | Default application objects |
| **Soft** | `java.lang.ref.SoftReference` | Reclaimed **only before `OutOfMemoryError`** | Memory-sensitive image/data caches |
| **Weak** | `java.lang.ref.WeakReference` | Reclaimed **on the very next GC cycle** | Canonical mappings (`WeakHashMap`) |
| **Phantom** | `java.lang.ref.PhantomReference`| Object has been finalized; memory unreleased | Safe off-heap memory deallocation |

---

## 2. Practical Memory-Sensitive Cache with `SoftReference`

```java
import java.lang.ref.SoftReference;

public class ImageCache {
    private SoftReference<byte[]> cachedImage;

    public void put(byte[] imageBytes) {
        this.cachedImage = new SoftReference<>(imageBytes);
    }

    public byte[] get() {
        if (cachedImage == null) return null;
        byte[] img = cachedImage.get(); // Returns null if GC cleared it under memory pressure!
        if (img == null) {
            System.out.println("Cache evicted by JVM GC. Reloading from disk...");
            img = loadFromDisk();
            put(img);
        }
        return img;
    }
}
```

## 3. `WeakHashMap`

In a `java.util.WeakHashMap`, keys are wrapped in `WeakReference`. When a key is no longer strongly referenced anywhere else in the application, its entry is automatically evicted during the next GC cycle.
