# 7.1 Garbage Collection Fundamentals & Generational Hypothesis

[← Back to Chapter 7: Garbage Collection & Serialization](./index.md)

Java’s Garbage Collector (GC) runs as a low-priority background daemon thread inside the JVM, reclaiming memory occupied by unreferenced objects on the Heap.

---

## 1. The Weak Generational Hypothesis

Empirical software engineering data reveals two universal truths across 99% of applications:
1. **Most objects die shortly after allocation** (local variables, temporary DTOs, HTTP request contexts).
2. **References from older generation objects to newer generation objects are exceedingly rare**.

Based on this principle, the JVM splits the Heap into two primary generations:

```
┌─────────────────────────────────────────────────────────────┐
│                       JVM Java Heap                         │
│ ┌──────────────────────────────────────┐ ┌────────────────┐ │
│ │ Young Generation                     │ │ Old Generation │ │
│ │ ┌──────────────┐ ┌────────┐ ┌──────┐ │ │ (Tenured)      │ │
│ │ │ Eden Space   │ │ From S0│ │ To S1│ │ │ Long-lived     │ │
│ │ │ (New objs)   │ │        │ │      │ │ │ survivors      │ │
│ │ └──────────────┘ └────────┘ └──────┘ │ │                │ │
│ └──────────────────────────────────────┘ └────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

1. **Young Generation**:
   - **Eden**: All new objects are born here.
   - **Survivor Spaces (S0 & S1)**: Objects surviving a Minor GC are copied back and forth between S0 and S1, incrementing their age counter.
   - When age exceeds `-XX:MaxTenuringThreshold` (default 15), the object is promoted to the **Old Generation**.
2. **Old Generation (Tenured)**:
   - Contains long-lived objects (e.g. Spring singletons, connection pools, static caches).
   - Collected during **Major / Full GC**, which is much slower and more resource-intensive.

---

## 2. GC Roots & Reachability Analysis

The JVM determines an object is garbage by tracing connectivity from **GC Roots**:
- Local variables in active thread stack frames.
- Active Java threads.
- Static fields in loaded classes.
- JNI (Java Native Interface) global and local references.

If no directed reference path exists from any GC Root to an object, that object is marked as **unreachable** and becomes eligible for collection.
