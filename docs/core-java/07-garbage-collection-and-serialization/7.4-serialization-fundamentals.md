# 7.4 Java Serialization & serialVersionUID

[← Back to Chapter 7: Garbage Collection & Serialization](./index.md)

**Serialization** is the process of converting an object's runtime state graph into a portable byte stream. **Deserialization** reconstructs an identical copy of that object graph in memory.

---

## 1. The `Serializable` Marker Interface

`java.io.Serializable` is a marker interface (contains zero methods). It signals to the JVM that instances of the class are safe to serialize using `ObjectOutputStream`:

```java
import java.io.*;

public class UserSession implements Serializable {
    private static final long serialVersionUID = 1L; // Mandatory version stamp

    private String userId;
    private String token;

    public UserSession(String userId, String token) {
        this.userId = userId;
        this.token = token;
    }
}
```

---

## 2. The `serialVersionUID` Contract

`serialVersionUID` serves as a version stamp for serialized classes:
- When deserializing an object via `ObjectInputStream`, the JVM compares the `serialVersionUID` in the stream against the `serialVersionUID` of the currently loaded class.
- If they differ, the JVM aborts and throws `InvalidClassException`.

### Why You Must Declare It Explicitly:
If you do not define `serialVersionUID`, the compiler automatically generates one based on class fields, methods, and interfaces. Any tiny change (adding a private method or comment) changes this compiler-generated hash, breaking backward compatibility with existing saved sessions!

```java
// Always declare explicit serialVersionUID in production!
private static final long serialVersionUID = 1L;
```

---

## 3. Serialization Security Vulnerabilities

Java native serialization is notoriously prone to **Remote Code Execution (RCE)** attacks via deserialization gadgets (e.g. Apache Commons Collections exploits). The JVM executes constructors and magic methods during deserialization without input validation.

:::warning Modern Enterprise Recommendation
Never expose Java native `ObjectInputStream` over public networks. Modern systems use typed data interchange formats like **JSON (Jackson)**, **Protocol Buffers (Protobuf)**, or **Avro**.
:::
