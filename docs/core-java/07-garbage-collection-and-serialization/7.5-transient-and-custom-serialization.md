# 7.5 Transient Fields & Custom Serialization

[← Back to Chapter 7: Garbage Collection & Serialization](./index.md)

Default Java serialization copies every non-static field across the entire object graph. You often need to exclude sensitive secrets or optimize network payload sizes.

---

## 1. The `transient` Keyword

Declaring an instance variable `transient` instructs the JVM serialization engine to skip that field:

```java
import java.io.Serializable;

public class AccountCredentials implements Serializable {
    private static final long serialVersionUID = 1L;

    private String username;
    
    // transient fields are NOT serialized; restored to default (null) on deserialization!
    private transient String rawPassword;
    private transient String encryptionKey;

    public AccountCredentials(String username, String rawPassword) {
        this.username = username;
        this.rawPassword = rawPassword;
    }
}
```

---

## 2. Custom Serialization with `writeObject` and `readObject`

To customize or encrypt serialized fields, define private callback methods:

```java
import java.io.*;

public class SecureDocument implements Serializable {
    private static final long serialVersionUID = 1L;

    private String title;
    private transient String confidentialPayload;

    private void writeObject(ObjectOutputStream oos) throws IOException {
        oos.defaultWriteObject(); // Serializes non-transient fields (title)
        // Custom encrypt before writing
        String encrypted = Base64.getEncoder().encodeToString(confidentialPayload.getBytes());
        oos.writeObject(encrypted);
    }

    private void readObject(ObjectInputStream ois) throws IOException, ClassNotFoundException {
        ois.defaultReadObject(); // Reads non-transient fields
        // Custom decrypt on restore
        String encrypted = (String) ois.readObject();
        this.confidentialPayload = new String(Base64.getDecoder().decode(encrypted));
    }
}
```

---

## 3. `Serializable` vs `Externalizable`

| Feature | `Serializable` | `Externalizable` |
| :--- | :--- | :--- |
| **Interface Type** | Marker interface (0 methods) | Contract with 2 methods (`writeExternal`, `readExternal`) |
| **Control** | Automatic JVM reflection | **100% manual control** by the developer |
| **Performance** | Slower (reflection overhead) | **Fastest** (Zero reflection overhead) |
| **Constructor Requirement** | No-arg constructor not required for target class | **Requires a public no-arg constructor** |
