# 8.5 Transient Fields, Custom Hooks & Externalizable

[← Back to Chapter 8: Garbage Collection & Serialization](./index.md)

Standard serialization blindly persists every non-static field in an object, which can leak security secrets or fail when non-serializable references are encountered.

---

## 1. The `transient` Keyword

Marking a field `transient` instructs the JVM serializer to ignore that field:
```java
public class UserAccount implements Serializable {
    private static final long serialVersionUID = 1L;

    private String username;
    private transient String passwordHash; // Excluded from binary payload
    private transient Connection dbConn;    // Non-serializable resource excluded
}
```
Upon deserialization, `transient` fields receive their JVM default value (`null`, `0`, `false`).

---

## 2. Custom Serialization Hooks: `writeObject` & `readObject`

By defining private methods with exact signatures, a class can intercept and customize its own serialization:

```java
public class SecureVault implements Serializable {
    private static final long serialVersionUID = 1L;
    private transient String secretKey;

    private void writeObject(ObjectOutputStream out) throws IOException {
        out.defaultWriteObject(); // Serializes all non-transient fields
        // Encrypt secret before writing to raw stream
        out.writeObject(encryptSecret(secretKey));
    }

    private void readObject(ObjectInputStream in) throws IOException, ClassNotFoundException {
        in.defaultReadObject(); // Reconstructs non-transient fields
        // Decrypt secret from stream
        String encrypted = (String) in.readObject();
        this.secretKey = decryptSecret(encrypted);
    }
}
```

---

## 3. `Externalizable`: Full Manual Stream Control

```java
public interface Externalizable extends Serializable {
    void writeExternal(ObjectOutput out) throws IOException;
    void readExternal(ObjectInput in) throws IOException, ClassNotFoundException;
}
```
- Completely bypasses JVM reflection overhead.
- You must manually serialize and deserialize every single field in exact order.
- **Requirement**: Must declare a `public` no-arg constructor!
