# 8.2 Functional Interfaces

[← Back to Chapter 8: Java 8 Features](./index.md)

A **Functional Interface** is an interface that contains exactly **one abstract method** (SAM - Single Abstract Method). Functional interfaces serve as the target types for lambda expressions and method references.

---

## 1. The `@FunctionalInterface` Annotation

The `@FunctionalInterface` annotation informs the Java compiler to enforce the SAM contract:

```java
@FunctionalInterface
public interface Calculator {
    int operate(int a, int b); // Single abstract method

    // Default and static methods do NOT violate the SAM contract
    default void log(String message) {
        System.out.println("Log: " + message);
    }

    static void info() {
        System.out.println("Calculator interface v1.0");
    }

    // Methods inherited from java.lang.Object do NOT count as abstract methods
    @Override
    boolean equals(Object obj);
}
```

> **Compiler Verification**: If an interface annotated with `@FunctionalInterface` declares more than one abstract method (or zero abstract methods), the compiler generates a compilation error.

## 2. Core Built-In Functional Interfaces (`java.util.function`)

Java 8 includes 40+ built-in functional interfaces in the `java.util.function` package. The four fundamental pillars are:

```
┌─────────────────┬───────────────────┬───────────────────────┬─────────────────────────┐
│ Interface       │ Method Signature  │ Purpose               │ Example                 │
├─────────────────┼───────────────────┼───────────────────────┼─────────────────────────┤
│ Predicate<T>    │ boolean test(T t) │ Conditional test      │ s -> s.isEmpty()        │
│ Function<T, R>  │ R apply(T t)      │ Transform input       │ s -> s.length()         │
│ Consumer<T>     │ void accept(T t)  │ Consume without return│ s -> System.out.println │
│ Supplier<T>     │ T get()           │ Factory / generate    │ () -> Math.random()     │
└─────────────────┴───────────────────┴───────────────────────┴─────────────────────────┘
```

## 3. Deep Dive into Core Interfaces

### 1. `Predicate<T>`
Evaluates a boolean condition against an input:
```java
Predicate<String> isLong = s -> s.length() > 5;
Predicate<String> startsWithA = s -> s.startsWith("A");

// Composing predicates
Predicate<String> validUser = isLong.and(startsWithA);
System.out.println(validUser.test("Alexander")); // true
System.out.println(validUser.test("Alex"));      // false
```

### 2. `Function<T, R>`
Accepts an argument of type `T` and transforms it to type `R`:
```java
Function<String, Integer> stringLength = s -> s.length();
Function<Integer, Integer> doubleValue = n -> n * 2;

// Function composition with andThen() and compose()
Function<String, Integer> pipeline = stringLength.andThen(doubleValue);
System.out.println(pipeline.apply("Java")); // (4) * 2 = 8
```

### 3. `Consumer<T>`
Accepts an argument and executes side-effects without returning a value:
```java
Consumer<String> printer = s -> System.out.println("Item: " + s);
Consumer<String> logger = s -> System.out.println("Logged: " + s);

// Chaining consumers with andThen()
Consumer<String> combined = printer.andThen(logger);
combined.accept("Order #101");
```

### 4. `Supplier<T>`
Takes no parameters and supplies an instance of type `T`:
```java
Supplier<Double> randomSupplier = () -> Math.random();
System.out.println(randomSupplier.get());

Supplier<List<String>> listFactory = ArrayList::new;
List<String> list = listFactory.get();
```

## 4. Binary Variants & Primitive Specializations

### Two-Argument Interfaces:
- **`BiPredicate<T, U>`**: `boolean test(T t, U u)`
- **`BiFunction<T, U, R>`**: `R apply(T t, U u)`
- **`BiConsumer<T, U>`**: `void accept(T t, U u)`
- **`BinaryOperator<T>`**: Extends `BiFunction<T, T, T>` where both arguments and the result share the same type.
- **`UnaryOperator<T>`**: Extends `Function<T, T>` where argument and result share the same type.

### Primitive Specializations (High Performance):
To eliminate autoboxing and unboxing overhead when processing primitives, use primitive specializations:
- `IntPredicate`, `LongPredicate`, `DoublePredicate`
- `IntFunction<R>`, `ToIntFunction<T>`, `IntToLongFunction`
- `IntConsumer`, `LongConsumer`, `DoubleConsumer`
- `IntSupplier`, `LongSupplier`, `DoubleSupplier`

```java
// Avoids boxing Integer -> int
IntPredicate isEven = n -> n % 2 == 0;
System.out.println(isEven.test(42)); // No autoboxing overhead!
```
