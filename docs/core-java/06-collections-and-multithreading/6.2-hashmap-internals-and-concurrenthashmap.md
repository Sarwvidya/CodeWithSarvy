# 6.2 HashMap Internals & ConcurrentHashMap

[← Back to Chapter 6: Collections & Multithreading](./index.md)

`java.util.HashMap` is the most frequently scrutinized data structure in enterprise Java engineering interviews and production systems.

---

## 1. How HashMap Works Internally

`HashMap` stores data in an internal array of **Node buckets**:
```java
transient Node<K,V>[] table;
```

### Key Constants
- **`DEFAULT_INITIAL_CAPACITY`**: 16 (Always a power of 2 for fast bitwise indexing `index = hash & (n - 1)`).
- **`DEFAULT_LOAD_FACTOR`**: 0.75 (Threshold before rehashing: `16 * 0.75 = 12` elements).
- **`TREEIFY_THRESHOLD`**: 8 (Converts linked-list bucket to Red-Black Tree when elements exceed 8).
- **`UNTREEIFY_THRESHOLD`**: 6 (Converts back to linked-list when elements drop to 6).
- **`MIN_TREEIFY_CAPACITY`**: 64 (Table capacity must reach 64 before treeification occurs).

---

## 2. Bucket Collision & Java 8 Treeification

When two keys hash to the same bucket index (Collision):

```
Bucket Array
┌────┐
│ 0  │ ──► null
├────┤
│ 1  │ ──► [Node: KeyA, ValA] ──► [Node: KeyB, ValB] (Singly Linked List, O(N))
├────┤
│ 2  │ ──► [TreeNode: Root]
│    │        ├── [TreeNode: Left]     (Converted to Red-Black Tree if >= 8, O(log N))
│    │        └── [TreeNode: Right]
└────┘
```

- **Prior to Java 8**: Collisions formed singly linked lists. In worst-case attack scenarios with malicious keys hashing to the same bucket, lookup degraded from **O(1) to O(N)** (Denial of Service).
- **Java 8+ Optimization**: When a bucket exceeds 8 nodes and table capacity >= 64, the linked list is transformed into a balanced **Red-Black Tree (TreeBin)**, guaranteeing **O(log N)** worst-case lookup!

---

## 3. `HashMap` vs `Hashtable` vs `ConcurrentHashMap`

| Feature | `HashMap` | `Hashtable` | `ConcurrentHashMap` |
| :--- | :--- | :--- | :--- |
| **Thread Safety** | ❌ No | ✅ Yes (`synchronized` methods) | ✅ Yes (Lock-free CAS + synchronized bucket heads) |
| **Performance** | Highest (single-thread) | Extremely slow (bottleneck) | High throughput concurrent reads/writes |
| **Null Keys/Values**| Allows 1 null key, many null values | ❌ Throws NPE | ❌ Throws NPE (prevents ambiguity) |
| **Locking Model** | None | Locks the **entire table** | Locks **only the specific bucket head** |
