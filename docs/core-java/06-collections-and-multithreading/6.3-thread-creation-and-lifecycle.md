# 6.3 Thread Lifecycle & Creation Models

[← Back to Chapter 6: Collections & Multithreading](./index.md)

A **Thread** is the smallest unit of execution dispatched by the operating system scheduler. In Java (prior to Project Loom), each `java.lang.Thread` mapped directly 1:1 to an underlying OS kernel thread.

---

## 1. The 6 Thread Lifecycle States (`Thread.State`)

```
               ┌───────────┐
               │    NEW    │
               └─────┬─────┘
                     │ thread.start()
                     ▼
             ┌───────────────┐
   ┌─────────┤   RUNNABLE    │◄────────┐
   │         └───────┬───────┘         │
   │ Waiting         │ wait() /        │ notify() /
   │ for monitor     │ join()          │ sleep() expired
   ▼                 ▼                 │
┌─────────┐   ┌───────────────┐        │
│ BLOCKED │   │ WAITING /     ├────────┘
└─────────┘   │ TIMED_WAITING │
              └───────┬───────┘
                      │ run() completes or uncaught exception
                      ▼
              ┌───────────────┐
              │  TERMINATED   │
              └───────────────┘
```

1. **`NEW`**: Instantiated (`new Thread()`) but `start()` has not been called.
2. **`RUNNABLE`**: Executing in JVM or queued in OS scheduler ready to run.
3. **`BLOCKED`**: Waiting to acquire an intrinsic monitor lock (`synchronized`).
4. **`WAITING`**: Waiting indefinitely for another thread (e.g. `wait()`, `join()`, `LockSupport.park()`).
5. **`TIMED_WAITING`**: Waiting for a specified time period (e.g. `sleep(ms)`, `wait(ms)`).
6. **`TERMINATED`**: The `run()` method has completed or threw an unhandled exception.

## 2. Three Ways to Define Tasks in Java

### A. Extending `Thread` (Not Recommended)
Couples task logic to thread lifecycle and prohibits extending any other class.

### B. Implementing `Runnable` (Standard Task)
Decouples work from thread execution:
```java
Runnable task = () -> {
    System.out.println("Running in: " + Thread.currentThread().getName());
};
new Thread(task).start();
```

### C. Implementing `Callable<V>` (Returns Value & Throws Checked Exception)
```java
Callable<String> worker = () -> {
    // Can return a value and throw checked exceptions!
    Thread.sleep(1000);
    return "SUCCESS";
};
```
