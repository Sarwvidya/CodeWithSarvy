# 6.1 Java Collections Framework Architecture

[← Back to Chapter 6: Collections & Multithreading](./index.md)

The Java Collections Framework (JCF) provides a unified architecture for storing, manipulating, and querying groups of objects.

---

## 1. Core Interface Hierarchy

```
                          java.lang.Iterable<E>
                                    ▲
                                    │
                         java.util.Collection<E>
             ┌──────────────────────┼──────────────────────┐
             │                      │                      │
       java.util.List<E>      java.util.Set<E>       java.util.Queue<E>
       • ArrayList            • HashSet              • PriorityQueue
       • LinkedList           • LinkedHashSet        • ArrayDeque
       • Vector / Stack       • TreeSet (SortedSet)  • BlockingQueue
```
*(Note: `java.util.Map<K, V>` does NOT inherit from `Collection` because it operates on key-value pairs rather than individual elements, though it is fully part of the framework).*

---

## 2. Complexity & Characteristics Matrix

| Collection | Underlying Data Structure | Access Time (By Index) | Search Time (By Value) | Insertion / Deletion | Ordering Guarantee | Allows Nulls? |
| :--- | :--- | :---: | :---: | :---: | :--- | :---: |
| **`ArrayList`** | Dynamic Resizable Array | **O(1)** | O(N) | O(N) amortized | Insertion order | ✅ Yes |
| **`LinkedList`** | Doubly Linked List | O(N) | O(N) | **O(1)** (at head/tail) | Insertion order | ✅ Yes |
| **`HashSet`** | Hash Table (`HashMap`) | N/A | **O(1)** avg | **O(1)** avg | **No ordering** | ✅ Yes (one) |
| **`LinkedHashSet`**| Hash Table + Doubly-linked list| N/A | **O(1)** avg | **O(1)** avg | Insertion order | ✅ Yes (one) |
| **`TreeSet`** | Red-Black Tree (`TreeMap`) | N/A | **O(log N)** | **O(log N)** | Natural / Comparator | ❌ No |
| **`ArrayDeque`** | Resizable Circular Array | O(1) (ends) | O(N) | **O(1)** (ends) | FIFO / LIFO order | ❌ No |

:::tip Production Recommendation: ArrayList vs LinkedList
Almost always prefer **`ArrayList`** over `LinkedList`. Modern CPU hardware architectures heavily favor contiguous array memory layouts due to CPU L1/L2 cache prefetching. `LinkedList` incurs huge memory overhead per node (24 bytes for prev/next pointers) and suffers severe cache misses.
:::
